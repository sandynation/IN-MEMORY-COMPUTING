# Chip A Virtual Core

Digital correction-core work for a post-von-Neumann in-memory computing tile.

## Included

- Bit-accurate TypeScript model and golden vectors
- RTL and testbench artifacts
- SKY130-oriented layout visualization
- Verification and DRC-flow notes

## Status

Chip A is a digital correction core validated through simulation and synthesis. It has not been fabricated or measured. The mixed-signal RRAM crossbar, column ADC, voltage-isolation circuits, and 128x128+ array validation remain open work.
